Escape the Computer Memory with
Little Computer Bug

All code is a little buggy, and Little Computer Bug just want to get home, but its stuck in the RAM! The developers keep trying to get rid of it with testing and debugging, can Little Computer Bug escape the RAM and get back safely?

Help Little Computer Bug get back home by avoiding the RAM modules and eating the bad code to extend their time in the system!

UP ARROW - MOVE UP
DOWN ARROW - MOVE DOWN
MODULES = -5 SECONDS ON TIMER
BAD CODE = +5 SECONDS ON TIMER
